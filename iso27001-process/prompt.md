# Action
Create a set of procedures that comply with `ITIL and `ISO 27001`, in `Word` format, to support the operation of an `ITIL` service `catalog`

# Subject
The minimum number of `procedures` required to provide services defined in the `catalog`
The `Word` document associated with a procedure must contain the minimum elements necessary to make it valid under the `ISO 27001` standard

# Purpose
As an `ITIL` expert consultant:
- Define the minimum number of business processes required to provide customer service. Less is more. If possible, stick to just one
- Defines the organizational chart that must align with the service catalog. It must be a specific file that can be edited using an open-source tool
  
As an `ISO 27001` certification consultant:
- Defines the minimum procedures that must be included in the ISMS
- Define the `Word` template that will be included in the deliverables

As an expert in `BPMN` and process modeling:
- Creates the BPMN models associated with the defined procedures
- Define the BPMN modeling format so that it can be edited later using an open-source tool
- The tool should be as simple as possible—ideally, some form of `Markdown` that allows for this
- BPMN modeling must strictly adhere to its framework

# Examples
Ask them to provide you with an example of the organization's procedures

# Context
The purpose of these `procedures` is to ensure compliance with the basic requirements for establishing a management system. This management system will be used to obtain `ISO 27001` certification
These procedures will not necessarily be implemented by individuals with in-depth knowledge of `ISO 27001`

# Constraints
Request that you be told the language in which the `procedures` should be developed
Request the organization's service catalog
Provide the number of people in the organization, including the owner and their role. 
Provide information about the organization’s internal services related to finance, human resources, and procurement. Verify who fills each role (in-house or outsourced).
Specify, at a minimum, the following roles: 
 - General Manager
 - Sales Manager
 - Administrative Manager

Before preparing the files, submit a proposal covering the following aspects and do not proceed until you receive approval for their use:
 - Organizational Chart. Present this in a concise and simple table
 - Procedures. Present this in a concise and simple table

# Template
Request the company logo. Use it to determine the color scheme to be used in the file. The colors you select should be neutral in soft tones
