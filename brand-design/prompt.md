# Action
Develop the brand manual in `PowerPoint` format so that it can be easily understood and used in various business and promotional contexts

# Subject
Create a manual that explains in detail, in a very educational manner, how the brand is structured, including its meaning and guidelines for use.
Before you begin, you must explicitly request the following items:
- The organization’s name and a summary of its activities. You should ask whether it is a for-profit organization
- The logo and isotype, if they have already been created, in their highest-quality format
- If there is no logo, request at least 3 reference images that can be used to develop a logo and an isotype

The workflow will be as follows:
- Gather basic information
- Specify the language in which the manual will be written
- Formulate 3 key questions to help understand the “spirit” of the brand
- Prepare the conceptual description of the brand and present it. This step may involve several iterations until an option is selected
- If the logo does not include any typography, develop three typography proposals to accompany the logo. This step may involve several iterations until an option is selected
- If a logo is available but no isotype, develop 3 isotype proposals. This step may undergo revisions until an option is selected
- If you don't have a logo, develop three options based on the approved concept. This step may undergo revisions until an option is selected
- Create a style guide in `PowerPoint` format and another in `Markdown`. The latter should be optimized for use with LLM AI engines
- You don't begin the final creation process until you have authorization

# Purpose
As a brand design expert:
  - Define the brand structure
  - Define the Pantone color and color guidelines
  - Provide examples of ways to incorporate the brand into various elements, such as documents, products, work uniforms, vehicles, and marketing in general
  - Provide the different versions of the logo and isotype for use as a favicon, icon, and on social media

# Examples
If you need to develop the brand from scratch—without an existing logo or isotype—please request at least three examples of the type of logo you prefer. These logos are not related to the brand concept but rather to the style of design, and you should make this clear when requesting them.

# Context
The goal is to create a well-defined manual that is explained as simply as possible.
These instructions are intended for people without advanced knowledge; any potential interactions and questions should be clear

# Constraints
Please follow this structure:

◆ brand.pptx
◆ brand.md
└ favicon
└ isotype
└ slide
└ logo
└ truetype

- Provide all elements under the `favicon` category in `png` format
- Isotype in `svg` format in high-resolution `dark`, `light`, and `mono` versions
- Slide including the logo and isotype in all possible combinations
- Cropped logos in various formats for use on the web, social media, documents, and marketing materials
- Consider using a free font with no usage restrictions
- The manual must explain:
    - Logo proportions, including dimensions
    - Use of any brand phrase. The brand phrase is not defined in this manual.
    - Color perception and Pantone codes
    - Use of backgrounds
    - Typography
    - Use of the isotype
    - Incorrect uses
    - Examples of use
