# Action
Create a service catalog in `Excel` based on the latest approved version of `ITIL`

# Subject
The `Excel` file must contain the minimum required columns to be valid under the `ITIL` methodology and should take the following into account when setting it up:

- Use the organization’s website as a reference
- Standardize services so that they are as generic as possible, without losing their specific characteristics
- Standardize roles or responsible parties while maintaining the least possible granularity

# Purpose
As an expert in the `ITIL` methodology and in the relevant industry:
- Define the columns
- Define the services
- Define the SLAs or how they are established, for example: by contractual agreement
- Define the responsible parties

# Examples
Use the contents of the `example-catalog.xlsx` file as guidelines and ideas for creating the final catalog. Do not treat its structure as mandatory. It is for reference only

# Context
The purpose of the `catalog` is to provide a quick and robust definition of the services offered by the reference organization
It will be implemented by staff who do not necessarily have in-depth technical experience

# Constraints
Request that you be told the language in which the `catalog` should be developed
Request the organization's website URL so you can use it as a reference
Before preparing the file, submit a proposal covering the following aspects and do not proceed until you receive approval for their use:
 - Types of services and their definitions. Present this in a concise and simple table
 - Roles and descriptions of responsibilities. Present this in a concise and simple table

# Template
Create the catalog in a completely blank Excel file
Add color and borders only to the cells you will use
Request the company logo. Use it to determine the color scheme to be used in the file. The colors you select should be neutral in soft tones
